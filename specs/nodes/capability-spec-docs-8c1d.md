Owns the governing-doctrine document set — `CLAUDE.md`, `SPEC.md`, `README.md`,
and `CONTRIBUTING.md` — together with everything under `docs/**`. These are the
repository's authoritative description of the spec-graph lifecycle, work-class
routing, the lane model, and the integration/coverage rules, plus the design
documents, entry-point orientation, and contribution guidance that surround them.

This is a dedicated docs capability, authored per `decision-lane-integration-9f3b`:
`CLAUDE.md` is deliberately NOT annexed into the spec-graph tooling capability
(`capability-spec-tooling-1a2b`) — the governing document is its own surface,
owned here.
