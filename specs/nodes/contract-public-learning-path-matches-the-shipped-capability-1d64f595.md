The README Quick Start, the Getting Started guide and the runnable core
Delivery example describe only behaviour this runtime actually has.

Acceptance:

A1: Setup shows explicit agent pack selection. No published command
    implies a pack is chosen for the user.
A2: The seven commands are described as commands, not as lifecycle
    stages. The fulfilment shape is named as what governs Brief to
    Evidence.
A3: The Evidence closure guard is documented, including that delivering
    again after a Review invalidates that Review.
A4: The commands shipped in this release are documented: doctor,
    upgrade, agent-pack, and baseline comparison.
A5: Nothing published claims a capability the release does not have, and
    the pre-release note on 0.0.1 is gone now that it is published.
