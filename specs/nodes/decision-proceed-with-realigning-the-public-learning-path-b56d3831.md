Alternatives considered: (a) update only the README Quick Start, leaving the
guide and example for later; (b) realign all three together against proven
behaviour; (c) rewrite the material around the new distribution surface as
its main subject.

(b) is selected. The three pieces are one path a new user walks, so leaving
any of them describing the old runtime would send that user into behaviour
that no longer exists. (a) leaves the walkthrough broken where it is most
concrete. (c) would sell the runtime's internals rather than teach the
Delivery, which is what the material is for.
