The README Quick Start, the Getting Started guide and the runnable core
Delivery example describe the runtime as it behaved before Checkpoint 1
was corrected: a silently selected agent pack, commands presented as
lifecycle stages, and no mention of the closure guards, doctor, upgrade or
explicit pack selection.

A new user following the published material would hit behaviour that no
longer exists. The public learning path has to match the shipped
capability.
